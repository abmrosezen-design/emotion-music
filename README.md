# Emotion Music

一个根据用户当前情绪、歌曲语言和曲风偏好，推荐一首能够陪伴此刻情绪的歌曲，并跳转到常用音乐平台搜索收听的响应式网站。

## 核心体验

1. 选择当前情绪。
2. 选择歌曲语言。
3. 选择歌曲类型。
4. 获得一句贴近当前情绪的话、一首推荐歌曲和推荐理由。
5. 前往网易云音乐、QQ 音乐或酷狗音乐搜索收听。
6. 通过“符合此刻”“换一首”和“此刻想对你说”反馈优化后续体验。

## MVP 原则

- 移动端优先的响应式网页。
- 强调“陪伴当前情绪”，不进行心理诊断。
- 第一版使用人工标注曲库和可解释的规则推荐。
- 无需注册或绑定音乐平台账号。
- 不在本站播放或下载完整音乐。
- 用户明确同意后，才匿名保存“此刻想对你说”的内容。
